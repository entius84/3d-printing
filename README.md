# 3D Printing & CAD Archive

A collection of functional prints, parametric OpenSCAD scripts, workshop jigs, furniture modifications, and custom peripheral accessories. 

## 📂 Repository Structure

```text
/3d-printing
├── keyboard-mods/          # Custom keyboard accessories (e.g., Epomaker TH80 Tablet Adapter)
├── workshop-jigs/          # Router templates, clamping aids, and tool holders
├── furniture-upgrades/     # Custom risers, desk spacers, and organization mods
├── electronics-lighting/   # Lamp housings, battery aligners, and PC mod components
└── openscad/               # Source code files (.scad) for parametric designs
